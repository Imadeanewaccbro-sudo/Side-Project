# Privacy Transmission Monitor — Implementation Plan

Status: approved implementation baseline.

This implementation builds the first protection core for camera, microphone, and location. It uses per-origin/per-permission policy, browser-level or extension-level mode, non-modal bottom-right alerts, local metadata only, and explicit limits around HTTPS visibility.

Phase 2 will add a real in-page Allow/Block decision UI and stronger synchronous extension-level interception. File-manager monitoring and agreement summarization are intentionally future phases.
